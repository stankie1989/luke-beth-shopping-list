# Luke & Beth's Shared Shopping List — v1.7.9

Meal Finder update, built from the confirmed working v1.7.8.2 source.

- Adds a "What can I cook?" tool to the Menu Planner.
- Search saved favourite meals using ingredients entered by the user.
- Ranks matches by the proportion of recipe ingredients available.
- Shows ingredients matched and ingredients missing.
- Offers to add only missing ingredients to a selected shopping list.
- Uses existing favourite meals and existing shopping-list picker.
- No database migration required.
